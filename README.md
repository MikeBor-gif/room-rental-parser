# Telegram-бот аренды: комнаты и квартиры Беларуси

### 👉 Открыть бота: [t.me/BOT_USERNAME](https://t.me/BOT_USERNAME)

Бот следит за **Kufar, Onliner и Realt** и присылает новые объявления об
аренде **комнат и квартир** по вашим фильтрам — с фото, ценой в белорусских
рублях и прямой ссылкой. Свежие объявления приходят в течение нескольких
минут после публикации, пока по ним ещё никто не позвонил.

**Города:** Минск, Брест, Витебск, Гомель, Гродно, Могилёв.

## Как пользоваться

1. Открыть бота и нажать **Старт**.
2. **➕ Добавить фильтр** — выбрать тип жилья, город и максимальную цену
   (кнопкой или своим числом).
3. Ждать. Новые объявления придут сами, повторов не будет.

Всё управление — кнопками, команды помнить не нужно:

| | |
|---|---|
| `/add` | новый фильтр (до 5 штук) |
| `/filters` | список фильтров, удалить или выключить |
| `/pause` · `/resume` | приостановить и вернуть рассылку |
| `/feedback` | написать автору — читаю всё |
| `/help` | справка |

Пользование бесплатное, без ограничений по времени и без рекламы.

**Цены всегда показываются в белорусских рублях.** Если объявление выставлено
в долларах, в карточке будет `4147 BYN (1350 USD)` — сравнивать со своим
фильтром можно напрямую.

# Для разработчиков

Ниже — техническая часть: как бот устроен внутри (см. также раздел
«Использование кода» в конце). Инфраструктура бесплатная: GitHub Actions +
cron-job.org + Supabase, своего сервера не нужно.

Премиум-подписка отключена (убрана из интерфейса), но её код оставлен
дормантным: интерфейс `PaymentProvider` (manual + каркас bepaid/Express-Pay),
`activate_premium`, админ-подтверждение платежей — всё на месте и включается
обратно.

## Архитектура

```
Пользователь ⇄ Telegram Bot API
                   ▲
                   │
┌──────────────────┴───────────────────────────────────────────┐
│ GitHub Actions (дёргается cron-job.org через workflow_dispatch)│
│                                                                │
│  bot.yml (~5 мин): getUpdates → роутер → меню, фильтры,        │
│                    отзывы, админ-команды                       │
│  scrape.yml (~5 мин): парсеры → новые объявления → матчинг     │
│                    по фильтрам → доставка (фото + ссылка)      │
└──────────────────┬────────────────────────────────────────────┘
                   ▼
     Supabase (Postgres) — пользователи, фильтры, объявления,
     очередь доставки, отзывы, платежи. Table Editor = готовая админка.
```

## Чек-лист запуска

1. **Supabase** — создать проект и таблицы: [docs/supabase-setup.md](docs/supabase-setup.md)
2. **Секреты GitHub** и **cron-job.org** (2 задания): [docs/deploy.md](docs/deploy.md)
3. **Оформление бота** в @BotFather: [docs/bot-setup.md](docs/bot-setup.md)
4. Написать боту `/start` и настроить первый фильтр 🎉

## Локальный запуск

```bash
python -m venv .venv && .venv/Scripts/activate   # Windows
pip install -r requirements.txt
cp .env.example .env                              # заполнить значения
python -m pytest -q                               # тесты
python -m src.main                                # один полный прогон
```

Режим демона на своей машине/VPS (вместо GitHub Actions):
`POLL_INTERVAL_SECONDS=120 python -m src.main` — и cron-job.org не нужен.

## Как добавить город

Одна запись в `src/cities.py` (код, имя, хэштег, координатная рамка) —
парсеры и меню бота подхватят её автоматически.

## Как добавить сайт-источник

Новый класс в `src/parsers/` по образцу `example_site.py`, регистрация
в `PARSER_CLASSES` (`src/jobs/scrape.py`). Интерфейс: `fetch() -> list[Listing]`.
